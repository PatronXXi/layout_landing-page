# Landing Page

This is my page for the "Landing" task. In this task, I used the following functions:
1) Animation
2) display:grid and most of its functions
3) Object states: hover, focus, ::after, transform, placeholder (-showm)
4) used a mixin, @include
5) icon states in the header block
6) implemented the nav block using a list
7) made the page responsive for phones, tablets, and laptops.

The layout is structured according to blocks:

1) header with a logo, buttons, and a mobile menu
2) Move Free section with a title and description
3) Compare Bikes section with cards for three bikes
4) Details section with photos and descriptions of benefits
5) Contacts section with a feedback form and contact information
The project is designed as a static page, without JavaScript logic.
